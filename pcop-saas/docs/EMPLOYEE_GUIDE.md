# Guide salarié — Utilisation quotidienne

## 1. Dashboard
Consulter les KPI : exposition, commissions, deals actifs, productivité.

## 2. CRM Transactions
Chaque deal devient une deal-room : acheteur, vendeur, valeur, statut, prochaine action.

## 3. Workflow
Chaque étape crée des tâches et livrables : KYC, ICPO, FCO, SPA, banking, shipping, commission.

## 4. Documents PDF
Le Document Studio permet de produire les livrables clients et internes. Dans cette version MVP, le bouton Generate PDF lance l'impression navigateur.

## 5. Rôles
- Admin : tout accès
- Operations : deals et workflow
- Compliance : KYC, AML, risk
- Banking : SWIFT, LC, SBLC
- Broker : origination et pipeline
- Viewer : lecture seule

## 6. Règle d'or
Aucune transaction ne passe à l'étape suivante sans statut compliance et document associé.
